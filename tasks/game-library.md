# Candidate game adapters

Minecraft Java26.2 is the first implemented adapter. Farming Simulator25 is the next planned integration investigation; it is not implemented.

Future adapters should be selected for accessible telemetry, bounded controls, reproducible test environments and a useful difference from Minecraft. Possible candidates include farming simulators, production/strategy games and driving simulators with documented mod or telemetry interfaces.

A local game scanner is planned, not implemented. Installed files, owned licenses, subscription availability and adapter compatibility are distinct facts. A scanner must not present any one of these as proof of the others. The engine should remain usable through manual adapter configuration.

Personal game-library inventories and account research are intentionally excluded from the public repository.
